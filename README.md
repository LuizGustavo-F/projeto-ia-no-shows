# Projeto de Previsão de No-Shows

Este projeto utiliza Redes Neurais (MLP) para analisar e prever a probabilidade de pacientes faltarem a consultas médicas.

**Dataset:** [Medical Appointment No-Shows no Kaggle](https://www.kaggle.com/datasets/msmstr/medical-appointment-no-shows)

## Análise

A análise completa, incluindo limpeza dos dados, construção do modelo e avaliação, está no notebook:
